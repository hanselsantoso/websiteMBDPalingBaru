# Serah terima website MBD dua bahasa

Build produksi lokal diuji pada 28 November 2026 menggunakan database QA. URL Indonesia tetap sama, dan English memakai awalan `/en`. Pilihan ID/EN tersedia di navigasi dan menu ponsel.

- [Panduan operator server dan VPS](deployment-preparation.md)
- [Panduan pengembang](panduan-pengembang.md)
- [Panduan admin dan pengisian konten](panduan-admin.md)
- [Panduan MCP untuk Cowork dan klien lain](mcp-konten.md)

## Hasil verifikasi

- Build, pemeriksaan TypeScript, 135 tes Vitest, dan 61 pemeriksaan CMS dan website lulus.
- Perpindahan locale mempertahankan slug, parameter URL, dan anchor. Pencarian artikel Inggris, detail mata kuliah, 12 studi kasus kuis sampai hasil, sitemap dan `hreflang` diuji.
- Seed memuat 563 padanan awal. Uji MCP memperbarui satu terjemahan di QA, memastikan halaman Inggris langsung berubah, lalu memulihkan nilai semula. Halaman Indonesia tetap menampilkan teks sumber.
- 248 screenshot mencakup 124 halaman publik pada desktop 1440 × 900 dan ponsel 390 × 844. Setiap halaman menghasilkan HTTP 200, locale HTML sesuai, dan gambar yang terlihat termuat.

Konten yang diberi label QA pada screenshot adalah konten contoh di database uji. Profil atau bagian yang masih bertanda *Pending* memerlukan data dari admin. Konten baru yang belum memiliki padanan Inggris akan menampilkan teks sumber.

Satu pemuatan halaman mata kuliah berbahasa Inggris melaporkan peringatan hidrasi pada batch terakhir. Rute itu lulus 16 pemuatan ulang dalam sesi browser terpisah. Manifest menyimpan hasil batch dan uji ulang.
